## `d02_sign_and_overflow`

The one trap that silently depends on where a value is written.

| | |
|---|---|
| box(int64(0) - 8) | `-8` |
| via named local, then box | `-8` |
| (int64(0) - 8) < 0 | `True` |
| Array store, inline positive | `8` |
